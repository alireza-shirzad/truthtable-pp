Throughout, a string column is given by its arithmetization of \cref{sec:string-arith}, and we write $s_i$ for the string held in row $i$.

\subsection{Layout Check}
\label{sec:proof-layout}
\cref{piop:layout-check} (\cref{sec:layout-check}) proves that the active characters of every active string occupy consecutive positions of the char-level columns, in order of their internal index, with $\mathsf{bnd}$ marking the first of them, and that inactive strings have no active characters:
\ifsp
\begin{displaymath}
\NPRelation_{\mathsf{Layout}} = \left\{\,
  \begin{aligned}
    & \NPInstance = \bot,\\
    & \NPInstancey = (\Oracle{\MLE{\mathsf{a}}}, \Oracle{\MLE{\mathsf{orig\text{-}ind}}}, \Oracle{\MLE{\mathsf{int\text{-}ind}}},\\
    & \phantom{\NPInstancey = (}\Oracle{\MLE{\mathsf{char\text{-}act}}}, \Oracle{\MLE{\mathsf{bnd}}}),\\
    & \NPWitness = (\mathsf{a}, \mathsf{orig\text{-}ind}, \mathsf{int\text{-}ind}, \mathsf{char\text{-}act}, \mathsf{bnd})\\[2pt]
    & \text{s.t.}\ \forall c\ \text{with}\ \mathsf{char\text{-}act}[c] = 1:\\
    & \phantom{\text{s.t.}}\ \quad \mathsf{bnd}[c] = \mathbf{1}[\mathsf{int\text{-}ind}[c] = 0],\\
    & \phantom{\text{s.t.}}\ \forall i:\ \text{the active } c \text{ with } \mathsf{orig\text{-}ind}[c] = i\\
    & \phantom{\text{s.t.}}\ \quad \text{are } p_i, \dots, p_i + m_i - 1,\\
    & \phantom{\text{s.t.}}\ \quad \text{with}\ \mathsf{int\text{-}ind}[p_i + j] = j\ \text{for}\ j < m_i,\\
    & \phantom{\text{s.t.}}\ \text{and}\ m_i = 0\ \text{if}\ \mathsf{a}[i] = 0
  \end{aligned}
\,\right\}.
\end{displaymath}
\else
\begin{displaymath}
\NPRelation_{\mathsf{Layout}} = \left\{\,
  \begin{aligned}
    \NPInstance &= \bot,\\
    \NPInstancey &= (\Oracle{\MLE{\mathsf{a}}}, \Oracle{\MLE{\mathsf{orig\text{-}ind}}}, \Oracle{\MLE{\mathsf{int\text{-}ind}}}, \Oracle{\MLE{\mathsf{char\text{-}act}}}, \Oracle{\MLE{\mathsf{bnd}}}),\\
    \NPWitness &= (\mathsf{a}, \mathsf{orig\text{-}ind}, \mathsf{int\text{-}ind}, \mathsf{char\text{-}act}, \mathsf{bnd})
  \end{aligned}
  \;\middle|\;
  \begin{array}{l}
    \forall c\ \text{with}\ \mathsf{char\text{-}act}[c] = 1:\ \mathsf{bnd}[c] = \mathbf{1}[\mathsf{int\text{-}ind}[c] = 0], \\[3pt]
    \forall i:\ \{c : \mathsf{char\text{-}act}[c] = 1,\ \mathsf{orig\text{-}ind}[c] = i\} = \{p_i, \dots, p_i + m_i - 1\} \\[3pt]
    \quad \text{for some } p_i, m_i \text{ with } \mathsf{int\text{-}ind}[p_i + j] = j \text{ for } j < m_i,\ \text{and } m_i = 0 \text{ if } \mathsf{a}[i] = 0
  \end{array}
\,\right\}.
\end{displaymath}
\fi
Combined with $\NPRelation_{\mathsf{Cons}}$, which fixes $m_i = \mathsf{a}[i]\mult\mathsf{l}[i]$, the relation says that the active characters of string $i$ are exactly the positions $p_i, \dots, p_i + \mathsf{l}[i] - 1$, with internal indices $0, \dots, \mathsf{l}[i]-1$ in that order; in particular the active pairs $(\mathsf{orig\text{-}ind}, \mathsf{int\text{-}ind})$ are distinct.
\parhead{Soundness and completeness}
Completeness is immediate from the layout of \cref{sec:string-arith}. For soundness, suppose all three steps accept. By the zero-indicator step, $\mathsf{bnd}[c] = \mathbf{1}[\mathsf{int\text{-}ind}[c] = 0]$ on every active $c$. By the predecessor lookup, for every active $c$ with $\mathsf{int\text{-}ind}[c] \ne 0$ there is an active $c'$ with $\idx_\mu(c') = \idx_\mu(c) - 1$, i.e.\ $c' = c - 1$, $\mathsf{orig\text{-}ind}[c-1] = \mathsf{orig\text{-}ind}[c]$ and $\mathsf{int\text{-}ind}[c-1] = \mathsf{int\text{-}ind}[c] - 1$ (with probability $1 - O(1/|\F|)$ over $\gamma$). Iterating from an active $c$ with $\mathsf{orig\text{-}ind}[c] = i$ and $\mathsf{int\text{-}ind}[c] = j$ yields active positions $c, c-1, c-2, \dots$ of string $i$ with internal indices $j, j-1, j-2, \dots$; since the hypercube has $2^\mu$ positions the walk cannot continue for more than $2^\mu$ steps, so $j$ is an integer below $2^\mu$ and the walk ends after exactly $j$ steps at an active position $c - j$ of string $i$ with internal index $0$. By the keyed sumcheck, string $i$ has exactly $\mathsf{a}[i]$ active positions with $\mathsf{bnd} = 1$, i.e.\ with internal index $0$; if $\mathsf{a}[i] = 0$ then no active character of $i$ exists, and otherwise there is a unique one, at some position $p_i$. Every active character of $i$ with internal index $j$ therefore sits at $p_i + j$, so distinct active characters of $i$ have distinct internal indices, and the set $J_i$ of internal indices present is closed downwards (the walk from $j$ passes through every smaller index), i.e.\ $J_i = \{0, \dots, m_i - 1\}$ with $m_i = |J_i|$. This is $\NPRelation_{\mathsf{Layout}}$.

\subsection{Lexicographic Sortedness Check}
\label{sec:proof-lexsorted}
\cref{piop:lex-sorted-check} (\cref{sec:lex-sorted-check}) proves that a string column with $n$ active rows in the contiguous layout is sorted in the lexicographic order of \cref{sec:sql-string-order}:
\ifsp
%% S&P (two-column): tuple and condition stacked so the display fits one column.
\begin{displaymath}
\NPRelation_{\mathsf{LexSorted}} = \left\{\,
  \begin{aligned}
    & \NPInstance = \bot,\\
    & \NPInstancey = \Oracle{\MLE{\strcol}},\\
    & \NPWitness = \strcol\\[2pt]
    & \text{s.t.}\ \mathsf{a} = \contig_{\mu,n},\\
    & \phantom{\text{s.t.}}\ s_i \lexle s_{i+1}\ \text{for all } 0 \le i < n-1
  \end{aligned}
\,\right\}.
\end{displaymath}
\else
\begin{displaymath}
\NPRelation_{\mathsf{LexSorted}} = \left\{\,
  \NPInstance = \bot,\;
  \NPInstancey = \Oracle{\MLE{\strcol}},\;
  \NPWitness = \strcol
  \;\middle|\;
  \begin{array}{l}
    \mathsf{a} = \contig_{\mu,n}, \\[3pt]
    s_i \lexle s_{i+1}\ \text{for all } 0 \le i < n-1
  \end{array}
\,\right\}.
\end{displaymath}
\fi
Only adjacent rows are constrained, which suffices because $\lexle$ is transitive.
\parhead{Soundness and completeness}
\Cref{ls:same} pins $\mathsf{same}$ exactly: a marked pair has equal hashes, hence equal strings by the collision resistance of the hash, and an unmarked pair of $\mathsf{t}_{\mathsf{in}}$ has distinct hashes. \Cref{ls:sort} then proves, for every pair of $\mathsf{eq}_0$, that the rows $(\mathsf{c}_0, \dots, \mathsf{c}_{R-1})[i]$ and $(\mathsf{c}_0, \dots, \mathsf{c}_{R-1})[i+1]$ are in strictly increasing lexicographic order, i.e.\ that there is a first position $k < R$ at which they differ and $\mathsf{c}_k[i] < \mathsf{c}_k[i+1]$ there. By \cref{ls:proj} these rows are the first $R$ entries of $\pad{s_i}$ and $\pad{s_{i+1}}$, so $s_i \lexlt s_{i+1}$ by \cref{lem:padded-lex}. Every pair of $\mathsf{t}_{\mathsf{in}}$ is thus either equal or strictly increasing, which is $\NPRelation_{\mathsf{LexSorted}}$. For completeness, the padded sequences of two distinct adjacent strings in a sorted column differ at some position, the first such position is at most the longer length, and the honest prover's $R$ is one more than the largest first-difference position over all adjacent distinct pairs, so after $R$ keys no pair of $\mathsf{eq}_0$ remains tied and the strict check passes.

\begin{ilemma}[No false negatives]\label{lem:prefilter-sound}
For every $\bigl(x; w\bigr)\in\mathcal{R}_{\mathsf{PF}}$, $\mathsf{a'}\le\mathsf{a}$ pointwise, $\mathsf{a'}$ is binary, and every active row that matches the pattern survives:
$\mathsf{a}[i]=1 \wedge \col[i]\sim\zeta \implies \mathsf{a'}[i]=1$.
\end{ilemma}
\begin{proof}
Each $\mathsf{fp}_b$ is a binary column committed by the data owner, so $\mathsf{a'}[i]\in\{0,1\}$ and $\mathsf{a'}[i]\le\mathsf{a}[i]$. If $\col[i]$ matches $\zeta$, then $\col[i]$ contains every character and n-gram of each maximal run of literal characters of a factor (a run never spans a \_), and every precedence pair of the factors read in order. Hence $\mathsf{fp}_b(\col[i])=1$ for every $b\in\mathcal{F}_\zeta\supseteq\mathcal{F}_u$, so the product is $1$ and $\mathsf{a'}[i]=\mathsf{a}[i]=1$.
\end{proof}
